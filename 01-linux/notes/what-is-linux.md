# What is Linux?

## The Linux Kernel
- The core of the operating system
- Manages hardware, memory, processes
- Every Linux distribution is built on top of the kernel

## What is a Linux Distribution (Distro)?
A distro = Linux kernel + tools + package manager + desktop environment (optional)

Examples:
- Ubuntu
- Debian
- Fedora
- CentOS / Rocky Linux
- Arch Linux

## Why Distros Exist
- Different goals (stability, security, speed)
- Different package managers (apt, yum, pacman)
- Different communities and support

## Where Linux Is Used
- Servers (most of the internet runs on Linux)
- Cloud platforms (AWS, Azure, GCP)
- DevOps tools (Docker, Kubernetes, Terraform)
- Networking equipment
- Security and penetration testing

## Key Takeaways
- Linux is everywhere in DevOps
- Distros are just different “flavours” of Linux
- The kernel is the heart of the OS
