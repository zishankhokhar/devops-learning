## Basic Linux Commands

### Navigation Commands
- pwd — show current directory  
- ls — list files and folders  
- cd — change directory  

### File & Folder Commands
- mkdir — create a folder  
- touch — create an empty file  
- cp — copy files  
- mv — move or rename files  
- rm — delete files  
- rmdir — delete empty folders  

### Viewing Files
- cat — print file contents  
- less — view file page by page  
- head — show first lines  
- tail — show last lines  

### Text & Search Commands
- echo — print text or variables to the terminal
- grep — search for text patterns inside files

### System Commands
- sudo — run as admin  
- apt update — refresh package list  
- apt install — install software  

### Useful Shortcuts
- Tab — auto‑complete  
- Ctrl + C — stop a command  
- Ctrl + L — clear the terminal 

### Manual Pages

- man — shows detailed documentation for commands, options, and usage

### What I learned

- How to navigate the filesystem using pwd, ls, and cd.
- How to create and manage files and folders using mkdir and touch.
- How to view file contents using cat and less.
- How to use sudo to run admin‑level commands and apt to update and install software.
