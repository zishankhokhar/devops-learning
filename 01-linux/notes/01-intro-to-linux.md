# Introduction to Linux

## What Linux Is
- Open-source operating system
- Built around the Linux kernel
- Used in servers, cloud, DevOps, networking, security

## Why DevOps Uses Linux
- Most servers run Linux
- Tools like Docker, Kubernetes, Terraform run best on Linux
- Automation and scripting are easier
- Cost effective and highly customisable

## Linux vs Windows vs Mac
- Linux = command-line focused
- Windows = GUI focused
- Mac = Unix-based but not Linux

## Key Takeaways
- Linux is essential for DevOps
- You will use the terminal every day
